# passes, when a filter matches nothing.
#
# Shards are balanced with the per-command seconds in tests/ci_durations.json. A new command
# without an entry there counts as 60 s; add its measured time when you know it. Each command
# must be self-contained: shards run on separate machines, so a command cannot rely on files
# another command wrote, and a shard runs several commands at once (build.yml's --jobs), so a
# command must not write a fixed path another command also uses (getTempDir() / "<test name>..."
# is fine). Check the plan with: python tests/run_ci_shard.py --check --of 8
