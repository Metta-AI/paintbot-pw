THE RUN

How the dungeon works

Call to Adventure is a deterministic four-hero expedition. The map is six stacked 128×128 slabs: Surface, Old Halls, Caves, Flooded Deep, Lava Hall, and the Vault. Ramps link the floors. One BASIC script drives each hero.

The party starts on the surface and fights down. When the vault is empty they turn around. On the climb, monsters respawn on floors above them every 15 seconds. Treasure is worth more the deeper it dropped. A hero banks gold only after reaching the surface. If everyone dies, the run is lost. If time runs out, the match ends wherever they stand.

Each class has a ten-ability HUD bar (keys 1–6, Q, E, R, F). The native AI spends combat on one primary strike, uses Chain Axe to pick up loot, and lets the cleric cast Healing Bloom. Damage rolls base + 0..spread, then a class power percent. Healing is negative damage and skips that percent.

THE DUNGEON

Monsters

Surface has no spawns. Deeper floors mix nastier species and add 10% hit points per level. Monsters swing Firebrand Sword at their own power percent, so they lose a straight damage race against the party.

Skeleton

OLD HALLS

60 HP base. Speed 2.20. Sight 6. Power 55%.

LAVA / VAULT

260 HP base. Speed 1.40. Sight 5. Power 110%. Often drops an idol.
