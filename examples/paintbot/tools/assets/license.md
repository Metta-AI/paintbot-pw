# Paintbot artwork

The Paint Crew concept, Heartwick level concept, cog robots, masonry cover,
and round cottages are original project artwork dedicated under CC0-1.0.
The images were generated for Paintbot. The models are constructed from
procedural primitives by the included Python source. Embedded grass and
masonry textures are the project's CC0 terrain tiles.

Imported from Metta-AI/paintbot-pw at 7b2b19f. No Unity Asset Store model,
texture, rig, animation, or material is included. Geometry and texture paths
are generated from the public art checkout alone.

The source scripts retain the repository's MIT code license. See ../LICENSE
for the complete CC0 dedication and ../LICENSE-CODE for source code terms.
